# ChristmasApp — Свидетели Рождества (веб-AR для печатного журнала)

Ребёнок наводит телефон на **круглый медальон** на странице журнала — и на нём встаёт 3D-свидетель и рассказывает,
как всё было, короткими фразами; вопросы — кнопками. Только веб, без приложения. ИИ нужен только при создании
(тексты, голоса, модели); у ребёнка всё играет из готовых файлов, без расходов на каждого пользователя.

## Запуск
```bash
npm install
npm run dev          # http://localhost:5173  (главная — список; /witness.html?id=zechariah — свидетель)
npm run build
```

## Что где
| Путь | Что |
|---|---|
| `index.html`, `witness.html`, `src/witness/` | **приложение**: список свидетелей и «стенд» (диск-медальон, модель, диалог) |
| `src/witness/stage.js` | сцена: медальон, «страница», фигура стоит вертикально; жесты, кивки, взгляд на зрителя |
| `src/witness/main.js` | диалог: рассказ (15 реплик подряд) + вопросы ребёнка (5), субтитры, пауза/пропуск |
| `data/witnesses.json`, `tools/witnesses_src.py` | **тексты**: 10 свидетелей × 20 реплик, теги подачи Eleven v4. Править в `witnesses_src.py` |
| `tools/export_witnesses.py` | собирает `data/witnesses.json`, `witnesses.md` и копирует в `public/data/` |
| `tools/voice_all.py` | озвучка недостающих реплик (ElevenLabs v4; ключ читается из `gospel-context/.env.local`) |
| `public/witnesses/<id>/model.glb` | модели (Meshy), сжатые: 0,5–1,2 МБ |
| `public/audio/witnesses/<id>/` | озвучка по репликам |
| `public/medallions/<id>.png` | медальоны (печатать в журнале; они же метки для распознавания) |
| `tools/gen-medallions.mjs` | генератор медальонов |
| `labs/`-страницы в корне (`magi.html`, `shepherd.html`, `pryanik.html`, `vertep.html`, …) | ранние эксперименты: фильмы-сцены, лупа, трекер Locus |
| `ar-tracker.html`, `src/main.js`, `src/smooth.js`, `src/lantern.js` | ранний прототип распознавания страницы (Locus AR) |
